# serve

**Trigger:** `/serve`

## Summary

Run the operator-plane JSON-RPC server (owera-cloud entry point over Cloudflare tunnel).

## Arguments

| Flag | Meaning |
|---|---|
| `--addr HOST:PORT` | Bind address (default 127.0.0.1:9091; production runs behind a Cloudflare tunnel). |
| `--ledger-dir PATH` | Ledger directory (default ~/.hermes/ledger). |
| `--shutdown-timeout DUR` | Max time to drain in-flight requests on SIGINT/SIGTERM. |

## Examples

**Default loopback bind:**

```
fleetctl serve
```

**Custom addr + ledger:**

```
fleetctl serve --addr 127.0.0.1:9091 --ledger-dir ~/.hermes/ledger
```
