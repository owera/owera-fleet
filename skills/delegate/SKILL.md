# delegate

**Trigger:** `/delegate`

## Summary

Run an ad-hoc shell command on one, all, or a random worker, and append a JSONL audit event per target.

## Arguments

| Flag | Meaning |
|---|---|
| `--node USER@HOST` | Target a single worker (mutually exclusive with --all/--random). |
| `--all` | Fan out to every entry in ~/.hermes/nodes.txt. |
| `--random` | Pick one node uniformly at random. |
| `--cmd "<string>"` | Remote shell command (required). |
| `--timeout DUR` | Per-node ssh connect + run cap (default 60s). |
| `--json` | Emit one JSON object per target to stdout. |
| `--quiet` | Suppress stdout; JSONL log is still written. |
| `--any-node` | Allow --node for a target not in nodes.txt. |

## Examples

**Run a probe on one worker:**

```
fleetctl delegate --node hermes@claw1.local --cmd "uname -a"
```

**Disk check across the fleet:**

```
fleetctl delegate --all --cmd "df -h /"
```

**JSON output for piping:**

```
fleetctl delegate --random --cmd "uptime" --json
```
