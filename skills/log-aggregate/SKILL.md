# log-aggregate

**Trigger:** `/log-aggregate`

## Summary

Pull every worker's ~/.hermes/logs/*.jsonl to the gateway over SSH (tar+gzip) and prune old aggregate copies. Wired to com.hermes.logaggregate (daily 03:45).

## Arguments

| Flag | Meaning |
|---|---|
| `--node USER@HOST` | Pull from one worker only (default: every entry in nodes.txt). |
| `--keep-days N` | Retention window for files under the landing dir (default 30; negative disables pruning). |
| `--json` | Emit one JSON object per pull to stdout. |
| `--quiet` | Suppress stdout; JSONL log still written. |
| `--dry-run` | Probe each worker but skip extract/prune/rotate. |
| `--rotate-on-pull` | Gzip the source *.jsonl files on each worker after a successful pull. |
| `--timeout DUR` | Per-node SSH connect + tar/extract cap (default 5m). |

## Examples

**Default fan-out across the fleet:**

```
fleetctl log-aggregate
```

**Targeted pull from one worker:**

```
fleetctl log-aggregate --node hermes@claw1.local
```

**Dry-run for capacity planning:**

```
fleetctl log-aggregate --dry-run --json
```
