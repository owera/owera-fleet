# alert

**Trigger:** `/alert`

## Summary

Fire a test alert through configured PagerDuty / OpsGenie / ntfy.sh backends.

## Arguments

| Flag | Meaning |
|---|---|
| `--title TITLE` | Alert title (required). |
| `--severity SEV` | critical\|warning\|info (default critical). |
| `--body BODY` | Alert body / description. |
| `--source SRC` | Alert source identifier. |
| `--dedup KEY` | Dedup key for supported backends. |

## Examples

**Critical pager test:**

```
fleetctl alert --title 'pager wiring test' --severity critical
```

**Info to chat only:**

```
fleetctl alert --title 'deploy ok' --severity info
```
