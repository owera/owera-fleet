# screensharing

**Trigger:** `/screensharing`

## Summary

Probe + toggle macOS Screen Sharing (com.apple.screensharing) across the fleet.

## Arguments

| Flag | Meaning |
|---|---|
| `status` | Report whether TCP/5900 is listening per host (no mutations, no sudo). |
| `enable` | Enable Screen Sharing on the targeted host(s). Requires NOPASSWD sudoers stanza (see setup-sudoers). |
| `disable` | Disable Screen Sharing on the targeted host(s). Same sudo requirement as enable. |
| `setup-sudoers` | Print the NOPASSWD sudoers stanza an admin should install into /etc/sudoers.d/fleetctl-screensharing on each host. |
| `--node USER@HOST` | Restrict to one worker (repeatable; default all entries in nodes.txt). |
| `--include-gateway=false` | Skip the gateway leg (default: gateway included). |
| `--ssh-timeout DUR` | Per-host SSH probe timeout. Default 30s. |
| `--action-timeout DUR` | Per-host launchctl ceiling. Default 30s. (enable/disable only) |
| `--json` | Emit one JSON object per host to stdout. (status only) |
| `--quiet` | Suppress stdout summary; JSONL log unchanged. |
