# state

**Trigger:** `/state`

## Summary

Regenerate ~/.hermes/ operational-state snapshot as markdown or JSON.

## Arguments

| Flag | Meaning |
|---|---|
| `--json` | Emit JSON instead of markdown. |
| `--out PATH` | Write to PATH instead of stdout. |
| `--hermes-dir DIR` | Override ~/.hermes/ (test/staging). |

## Examples

**Regenerate STATE.md in-place:**
