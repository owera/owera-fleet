# logrotate

**Trigger:** `/logrotate`

## Summary

Gzip-rotate ~/.hermes/logs/*.jsonl files above the size threshold; supersedes the hermes-setup bash rotator.

## Arguments

| Flag | Meaning |
|---|---|
| `--threshold-bytes N` | Rotate files at or above this size in bytes. Default 1 MiB (env: HERMES_LOG_ROTATE_THRESHOLD). |
| `--keep N` | Keep this many newest rotations per log. Default 5 (env: HERMES_LOG_ROTATE_KEEP). |
| `--dry-run` | Plan only; touch nothing. |
| `--quiet` | Suppress stderr summary; JSONL log unchanged. |
| `install / uninstall / status` | launchd lifecycle for com.owera.logrotate (daily 03:30). |
