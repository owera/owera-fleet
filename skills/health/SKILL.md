# health

**Trigger:** `/health`

## Summary

Report fleet health: gateway LaunchAgents and SSH worker checks.

## Arguments

| Flag | Meaning |
|---|---|
| `--node USER@HOST` | Probe one worker via SSH. |
| `--all` | Probe every entry in ~/.hermes/nodes.txt. |
| `--json` | Emit JSON array instead of markdown. |
| `--quiet` | Suppress stdout; JSONL log still written. |
| `--timeout DUR` | Per-node SSH connect+run cap (default 30s). |
| `--hermes-dir PATH` | Override ~/.hermes path. |

## Examples

**Gateway-only health check:**

```
fleetctl health
```

**All workers health:**

```
fleetctl health --all
```

**One worker in JSON:**

```
fleetctl health --node hermes@claw1.local --json
```
