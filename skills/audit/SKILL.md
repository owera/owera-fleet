# audit

**Trigger:** `/audit`

## Summary

Summarise fleet JSONL audit logs with filtering by phase, node, result, and time.

## Arguments

| Flag | Meaning |
|---|---|
| `--log FILE` | Specific JSONL file(s) to scan (default: all in ~/.hermes/logs/). |
| `--since DATE` | Only events at or after this time (RFC3339 or YYYY-MM-DD). |
| `--phase PHASE` | Filter by phase (delegate, health, bootstrap, …). |
| `--node NODE` | Filter by node (substring match). |
| `--result RESULT` | Filter by result: ok, error, warn, no-change, skipped. |
| `--json` | Emit JSON array of matching events. |
| `--hermes-dir PATH` | Override ~/.hermes path. |

## Examples

**Show all recent events:**

```
fleetctl audit
```

**Show only errors:**

```
fleetctl audit --result error
```

**Delegate events since May 2026:**

```
fleetctl audit --phase delegate --since 2026-05-01
```
