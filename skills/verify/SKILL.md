# verify

**Trigger:** `/verify`

## Summary

Run the WS-12 Phase-1 verification gate: build / vet / test / skills-drift + six self-tests.

## Arguments

| Flag | Meaning |
|---|---|
| `--json` | Emit the report as JSON instead of a text table. |
| `--check ID` | Only run check(s) with this ID (repeatable: --check go_test --check ledger_self). |
| `--repo PATH` | Override repo root (default: walk up from cwd looking for go.mod). |
| `--parallel N` | Maximum concurrent checks (default 4). |
| `--hermes-dir PATH` | Override ~/.hermes path (also redirects the JSONL log). |
| `--quiet` | Suppress text/JSON output; still emits the audit event and exit code. |

## Examples

**Run the full gate:**

```
fleetctl verify
```

**Run only the test phase:**

```
fleetctl verify --check go_test
```

**Machine-readable report:**

```
fleetctl verify --json
```
