# test

**Trigger:** `/test`

## Summary

Run fleet test scenarios from scenarios/*.yaml — PASS/FAIL per scenario.

## Arguments

| Flag | Meaning |
|---|---|
| `--scenario NAME` | Comma-separated scenario names to run (default: all). |
| `--tier N` | Run only tier-N scenarios: 1=smoke, 2=usecase, 3=e2e. |
| `--scenarios-dir PATH` | Directory with *.yaml scenario files (default: scenarios/). |
| `--continue-on-fail` | Keep running after the first failure. |
| `--timeout DUR` | Per-step timeout (default 5m). |
| `--quiet` | Suppress per-step output; JSONL log still written. |

## Examples

**Run all smoke scenarios:**

```
fleetctl test --tier 1
```

**Run named scenarios:**

```
fleetctl test --scenario smoke,health
```

**Run everything, don't stop on fail:**

```
fleetctl test --continue-on-fail
```
