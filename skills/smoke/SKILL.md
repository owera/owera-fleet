# smoke

**Trigger:** `/smoke`

## Summary

Probe a worker's SSH reachability via the gateway's Keychain-backed agent key.

## Arguments

| Flag | Meaning |
|---|---|
| `user@host (positional)` | Explicit target; overrides --node and nodes.txt. |
| `--node USER@HOST` | Target override when no positional arg. |
| `--known-hosts PATH` | Use an alternate known_hosts file. |
| `--strict-host-key` | Refuse to accept new host keys; require an existing entry. |
| `--timeout DUR` | Overall probe timeout (default 15s). |

## Examples

**Probe a specific worker:**

```
fleetctl smoke hermes@claw1.local
```

**Probe the first node in nodes.txt:**

```
fleetctl smoke
```
