# heartbeats-bridge

**Trigger:** `/heartbeats-bridge`

## Summary

Refresh ~/.hermes/heartbeats/<host>.json from per-worker SSH probes so fleet.HealthSnapshot sees them.

## Arguments

| Flag | Meaning |
|---|---|
| `--interval DUR` | Poll interval (≥10s). Default 60s. |
| `--stale-max DUR` | Treat worker heartbeats older than this as dead. Default 5m. |
| `--ssh-timeout DUR` | Per-worker SSH probe timeout. Default 10s. |
| `--once` | Run a single sweep and exit (CI / ad-hoc shape). |
| `install / uninstall / status` | launchd lifecycle for the daemon. |
