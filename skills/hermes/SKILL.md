# hermes

**Trigger:** `/hermes`

## Summary

Audit and reconcile per-node hermes-agent config (LLM auth keys + model).

## Arguments

| Flag | Meaning |
|---|---|
| `audit` | Read-only per-node status. Add --json or --node user@host. |
| `sync` | Push gateway auth keys + model to selected workers. --all, --node, --no-model, --dry-run. |
| `ensure-config` | Audit, then sync any nodes that need setup. Idempotent. |

## Examples

**See which nodes are configured.:**

```
fleetctl hermes audit
```

**Make every worker match gateway (keys + model).:**

```
fleetctl hermes ensure-config
```

**Sync just one node.:**

```
fleetctl hermes sync --node hermes@claw1.local
```
