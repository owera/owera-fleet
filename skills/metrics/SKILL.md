# metrics

**Trigger:** `/metrics`

## Summary

Serve or scrape Prometheus-format metrics derived from JSONL logs, ledger, heartbeats.

## Arguments

| Flag | Meaning |
|---|---|
| `--serve` | Start an HTTP /metrics server. |
| `--scrape` | Print current metrics once and exit. |
| `--addr ADDR` | Listen address (default 127.0.0.1:9090). |
| `--log-dir PATH` | Override ~/.hermes/logs path. |

## Examples

**Start metrics server:**

```
fleetctl metrics --serve
```

**Scrape once:**

```
fleetctl metrics --scrape
```
