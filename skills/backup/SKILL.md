# backup

**Trigger:** `/backup`

## Summary

Snapshot ~/.hermes/ via restic (supersedes the hermes-setup bash com.hermes.backup).

## Arguments

| Flag | Meaning |
|---|---|
| `--dry-run` | Pass --dry-run to restic backup; skip forget+prune. |
| `--tag NAME` | Restic tag for this snapshot family. Default hermes-state. |
| `--keep-daily N / --keep-weekly N / --keep-monthly N` | Restic retention. Defaults 7 / 4 / 6. |
| `--quiet` | Suppress stderr summary. |
| `install / uninstall / status` | launchd lifecycle for com.owera.backup (daily 03:15). install reads RESTIC_REPOSITORY + RESTIC_PASSWORD_COMMAND from env and bakes them into the plist. |
