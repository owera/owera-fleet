# health-diff

**Trigger:** `/health-diff`

## Summary

Diff two fleet-health-snapshot reports; classify each change by severity (info/warn/crit) and exit non-zero on warn-or-above. Supersedes the hermes-setup bash differ.

## Arguments

| Flag | Meaning |
|---|---|
| `<fromReport> <toReport>` | Positional snapshot paths. Override --from/--to when given. |
| `--from PATH` | Older snapshot. Pair with --to. |
| `--to PATH` | Newer snapshot. Pair with --from. |
| `--format FMT` | Output format: markdown (default) or json. markdown is the human bullet list; json is machine-parseable. |
| `--no-log` | Skip appending to ~/.hermes/logs/fleet-health-diff.jsonl. |

## Examples

**Diff the two newest snapshots in ~/.hermes/reports/:**

```
fleetctl health-diff
```

**Diff two specific files:**

```
fleetctl health-diff a.md b.md
```

**CI gate (exits non-zero on warn-or-above):**

```
fleetctl health-diff --format json
```
