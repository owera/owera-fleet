# backup-worker

**Trigger:** `/backup-worker`

## Summary

rsync each worker's ~/.hermes/ into the gateway tree (supersedes the hermes-setup bash com.hermes.backup-worker).

## Arguments

| Flag | Meaning |
|---|---|
| `--dry-run` | Pass --dry-run -i to rsync; touch no destination files. |
| `--node USER@HOST` | Restrict to this worker (repeatable; default all entries in nodes.txt). |
| `--bwlimit KB/s` | rsync --bwlimit in KB/s. 0 = unthrottled. |
| `--ssh-timeout DUR` | rsync ssh -o ConnectTimeout value. Default 15s. |
| `--quiet` | Suppress stderr summary. |
| `install / uninstall / status` | launchd lifecycle for com.owera.backup-worker (daily 03:05). |
