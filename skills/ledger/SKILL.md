# ledger

**Trigger:** `/ledger`

## Summary

Inspect and verify the signed per-task ledger (list tasks, show entries, verify signatures).

## Arguments

| Flag | Meaning |
|---|---|
| `list` | List all task IDs. |
| `show <task-id>` | Show entries for a task. |
| `verify` | Verify ed25519 signatures across all ledger tasks. |
| `--ledger-dir PATH` | Override ~/.hermes/ledger path. |
| `--json` | Emit JSON output. |

## Examples

**List tasks:**

```
fleetctl ledger list
```

**Show task entries:**

```
fleetctl ledger show task-abc123
```

**Verify all signatures:**

```
fleetctl ledger verify
```
