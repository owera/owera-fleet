# watchdog

**Trigger:** `/watchdog`

## Summary

Fire alerts when ~/.hermes/heartbeats/<host>.json mtimes go stale (replaces the hermes-setup bash watchdog).

## Arguments

| Flag | Meaning |
|---|---|
| `--interval DUR` | Scan interval (≥10s). Default 120s. |
| `--stale-max DUR` | Treat heartbeats older than this as stale. Default 5m. |
| `--dedup-window DUR` | Minimum gap between repeat stale alerts per host. Default 1h. |
| `--once` | Run a single scan and exit non-zero if any host is stale. |
| `install / uninstall / status` | launchd lifecycle for com.owera.watchdog. |
