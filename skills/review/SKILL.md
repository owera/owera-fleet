# review

**Trigger:** `/review`

## Summary

Code-review a git branch by delegating the diff to the Hermes agent.

## Arguments

| Flag | Meaning |
|---|---|
| `--branch BRANCH` | Git branch to review (default: current branch). |
| `--out FILE` | Write markdown report to FILE (default: stdout). |
| `--json` | Emit JSON instead of markdown. |
| `--quiet` | Suppress stdout; JSONL log still written. |
| `--hermes-dir PATH` | Override ~/.hermes for log path. |

## Examples

**Review current branch:**

```
fleetctl review
```

**Review a specific branch:**

```
fleetctl review --branch feature/my-work
```

**Save report to file:**

```
fleetctl review --out /tmp/review.md
```
