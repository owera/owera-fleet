# brew

**Trigger:** `/brew`

## Summary

Probe + install Homebrew essentials across the fleet (supersedes scripts/fleet-brew-baseline.sh).

## Arguments

| Flag | Meaning |
|---|---|
| `probe` | Report Homebrew state per host (no mutations). Non-zero exit when any host is missing brew or essentials. |
| `install` | Install missing essentials on hosts that already have brew. Hosts without brew get a remediation pointer. |
| `--essentials "LIST"` | Space-separated formula list. Default: jq coreutils shellcheck gh wget ripgrep. |
| `--node USER@HOST` | Restrict to one worker (repeatable; default all entries in nodes.txt). |
| `--include-gateway=false` | Skip the gateway leg (default: gateway included). |
| `--ssh-timeout DUR` | Per-host SSH probe timeout. Default 30s. |
| `--install-timeout DUR` | Per-host install ceiling. Default 5m. (install only) |
| `--force` | Re-run install even on hosts with all essentials already present. (install only) |
| `--quiet` | Suppress stdout summary; JSONL log unchanged. |
