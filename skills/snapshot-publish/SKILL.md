# snapshot-publish

**Trigger:** `/snapshot-publish`

## Summary

Periodically write the operator-plane HealthSnapshot JSON to disk (and optionally PUT to R2/S3) for the status page to consume.

## Arguments

| Flag | Meaning |
|---|---|
| `--out PATH` | Destination file (atomic via .tmp + rename). Default ~/.hermes/state/health-snapshot.json. |
| `--interval DUR` | Poll interval (≥1s; matches the HealthSnapshot cache TTL). Default 30s. |
| `--once` | Write a single snapshot and exit (CI / ad-hoc shape). |
| `--http-put URL` | Also PUT the JSON body to this URL each cycle (env fallback: OWERA_SNAPSHOT_HTTP_PUT_URL). Failures are logged but don't halt the loop. |
| `--http-header K=V` | Repeatable header for --http-put requests (env fallback: OWERA_SNAPSHOT_HTTP_AUTH → Authorization). |
| `--http-timeout DUR` | Per-request timeout for --http-put. Default 10s. |
