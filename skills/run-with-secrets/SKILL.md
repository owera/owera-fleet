# run-with-secrets

**Trigger:** `/run-with-secrets`

## Summary

Execute a command with secrets delivered via stdin (never via env vars or argv).

## Arguments

| Flag | Meaning |
|---|---|
| `--secret KEY=VALUE` | Secret key-value pair (repeatable). |
| `--env-file FILE` | Load secrets from a KEY=value file. |
| `--use-env` | Inject secrets as env vars instead of stdin (opt-in). |

## Examples

**Deliver token via stdin:**

```
fleetctl run-with-secrets --secret TOKEN=abc123 -- sh ./deploy.sh
```

**Load from .env file:**

```
fleetctl run-with-secrets --env-file .env -- python task.py
```
