# research

**Trigger:** `/research`

## Summary

Delegate a research query to the Hermes agent and capture the response as a markdown report.

## Arguments

| Flag | Meaning |
|---|---|
| `--prompt TEXT` | Research query (required). |
| `--web` | Enable Hermes web toolset for live browsing. |
| `--out FILE` | Write report to FILE (default: stdout). |
| `--quiet` | Suppress stdout; JSONL log still written. |
| `--hermes-dir PATH` | Override ~/.hermes path. |

## Examples

**Research a topic:**

```
fleetctl research --prompt "Go 1.24 release notes"
```

**Research with web browsing:**

```
fleetctl research --prompt "Latest restic changelog" --web
```

**Save to file:**

```
fleetctl research --prompt "SSH agent forwarding macOS" --out /tmp/r.md
```
