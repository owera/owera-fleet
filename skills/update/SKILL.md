# update

**Trigger:** `/update`

## Summary

Check or upgrade the hermes binary on fleet workers via SSH.

## Arguments

| Flag | Meaning |
|---|---|
| `--node USER@HOST` | Target one worker. |
| `--all` | Target every node in ~/.hermes/nodes.txt. |
| `--dry-run` | Report version status without making changes. |
| `--version VERSION` | Pin to a specific hermes version. |
| `--quiet` | Suppress stdout; JSONL log still written. |
| `--timeout DUR` | Per-node SSH cap (default 60s). |

## Examples

**Dry-run check across the fleet:**

```
fleetctl update --all --dry-run
```

**Upgrade one worker:**

```
fleetctl update --node hermes@claw1.local
```

**Upgrade to specific version:**

```
fleetctl update --all --version v0.14.0
```
