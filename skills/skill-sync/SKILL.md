# skill-sync

**Trigger:** `/skill-sync`

## Summary

Sign and pull skill bundles to workers via a signed-Git source verified by a pinned ed25519 public key.

## Arguments

| Flag | Meaning |
|---|---|
| `init` | Generate the gateway signing key pair under ~/.hermes/skillsync/. |
| `sign --src DIR` | Hash DIR and write a signed manifest inside it. |
| `pull --git-url URL [--apply]` | Clone or fetch the remote, verify, and optionally apply to ~/.claude/skills/agentic-services/. |
| `verify --git-url URL` | Clone and verify only; do not apply. |
| `--key-dir DIR` | Override signing key directory (default ~/.hermes/skillsync). |
| `--branch NAME` | Remote branch (default main). |
| `--skills-dir PATH` | Path within the repo containing the bundle (default skills). |
| `--pub-key BASE64` | Override the pinned public key (default: signing.pub in --key-dir). |
| `--local-dir DIR` | Persistent local working tree (default ~/.hermes/skillsync/checkout). |
| `--dest DIR` | Apply destination (default ~/.claude/skills/agentic-services). |

## Examples

**Init signing key on the gateway:**

```
fleetctl skill-sync init
```

**Sign a skills directory:**

```
fleetctl skill-sync sign --src ./skills --bundle-id v1
```

**Pull and apply on a worker:**

```
fleetctl skill-sync pull --git-url https://github.com/owera/owera-fleet.git --apply
```

**Verify only (no apply):**

```
fleetctl skill-sync verify --git-url https://github.com/owera/owera-fleet.git
```
