# bootstrap-worker

**Trigger:** `/bootstrap-worker`

## Summary

Provision a worker by running the multi-phase bootstrap pipeline (phase00..phase09).

## Arguments

| Flag | Meaning |
|---|---|
| `--node USER@HOST` | Target worker (required). |
| `--phase SCRIPT` | Run a single named phase script instead of all 10. |
| `--script-dir PATH` | Override the local remote/ directory. |
| `--pinned-version TAG` | Override pinned Hermes version (phase03 + phase09). |
| `--pinned-version-file PATH` | File to read pinned version from (default ~/.hermes/PINNED_VERSION). |
| `--config-src DIR` | Gateway-side hermes state dir to bundle for phase04 (default ~/.hermes). |
| `--env-gpg PATH` | Gateway-side .env.gpg to distribute (phase05). |
| `--secrets-wrapper PATH` | Override run-with-secrets.sh wrapper (phase05). |
| `--dedicated-key PATH` | Gateway-side dedicated SSH key path; .pub is uploaded (phase06). |
| `--plist-template PATH` | Heartbeat plist template (phase08). |
| `--gateway-hermes-prefix DIR` | Gateway hermes-state prefix rewritten by phase04 (default ~/.hermes). |
| `--allow-existing-admin-user` | Allow pre-existing 'hermes' user in admin group (phase02 + phase09). |
| `--skip-tirith` | Skip phase07 + phase09 tirith probe. |
| `--skip-heartbeat` | Skip phase08 + phase09 heartbeat probe. |
| `--heartbeat-wait-seconds N` | First-heartbeat wait window (phase08). |
| `--uid N` | UID for the hermes service account (phase02). Default 502; override when occupied on target. |
| `--dry-run` | Pass --dry-run to phase scripts (probe only, no mutations). |
| `--timeout DUR` | Per-phase timeout (default 10m). |
| `--quiet` | Suppress stdout; JSONL log still written. |

## Examples

**Full bootstrap (all 10 phases):**

```
fleetctl bootstrap-worker --node hermes@claw1.local
```

**Dry-run probe:**

```
fleetctl bootstrap-worker --node hermes@claw1.local --dry-run
```

**Single phase:**

```
fleetctl bootstrap-worker --node hermes@claw1.local --phase phase09_verify.sh
```
