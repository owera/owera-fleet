# gen-skills

**Trigger:** `/gen-skills`

## Summary

Render skills/<name>/SKILL.md from every fleetctl subcommand's Skill() declaration.

## Arguments

| Flag | Meaning |
|---|---|
| `--skills-dir DIR` | Override output root (default: skills/). |
| `--check` | Compare on-disk to generated; exit 1 on drift (no writes). Used by CI. |

## Examples

**Regenerate all skills:**

```
fleetctl gen-skills
```

**CI drift gate:**

```
fleetctl gen-skills --check
```
