# cronjob

**Trigger:** `/cronjob`

## Summary

Manage Hermes-managed cron jobs (long-running pollers run inside the Hermes runtime).

## Arguments

| Flag | Meaning |
|---|---|
| `list` | List all Hermes cron jobs. |
| `install --name N --schedule S --command C` | Install or update a job. |
| `remove <name>` | Remove a job by name. |
| `status <name>` | Show a job's state + last run. |
| `--env KEY=VALUE` | Per-job env var (repeatable). |
| `--tag T` | Per-job tag (repeatable). |

## Examples

**Install ticket triage poller:**

```
fleetctl cronjob install --name triage --schedule '*/5 * * * *' --command 'hermes z "triage ticket queue"'
```

**List jobs as JSON:**

```
fleetctl cronjob list --json
```
