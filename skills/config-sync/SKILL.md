# config-sync

**Trigger:** `/config-sync`

## Summary

Sign and push config bundles to worker nodes; verify with pinned ed25519 public key.

## Arguments

| Flag | Meaning |
|---|---|
| `init` | Generate the gateway signing key pair. |
| `pack --src DIR --out FILE` | Create a signed bundle. |
| `verify --in FILE` | Verify a bundle without extracting. |
| `apply --in FILE --dest DIR` | Verify and unpack a bundle. |

## Examples

**Init key pair:**

```
fleetctl config-sync init
```

**Pack hermes config:**

```
fleetctl config-sync pack --src ~/.hermes/config --out /tmp/bundle.tar
```

**Apply on worker:**

```
fleetctl config-sync apply --in bundle.tar --dest ~/.hermes/config
```
