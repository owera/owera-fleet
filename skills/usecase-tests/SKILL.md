# usecase-tests

**Trigger:** `/usecase-tests`

## Summary

Operator-shaped end-to-end test pass over the 10 scenarios the v2 deployment plan ships (delegation, review, research, observation, lifecycle, resilience).

## Arguments

| Flag | Meaning |
|---|---|
| `--scenario S1,...` | Comma-separated scenario IDs. Default: all 10. |
| `--format markdown|json` | Output format. Default markdown. |
| `--continue-on-fail` | Run every selected scenario even after a FAIL. |
| `--skip-llm` | Skip S4 and run S3 in structural-coverage-only mode. |
| `--free-model NAME` | OpenRouter free-tier model for S3/S4. Default openai/gpt-oss-120b:free. |
| `--review-repo PATH` | Repo for S3 git-stat. Default cwd. |
| `--review-base REF` | Base ref for S3 diff. Default HEAD~5 (falls back to HEAD~1 on shallow clones). |
| `--research-topic STR` | Topic for S4 research query. |
| `--hermes-dir PATH` | Override ~/.hermes (used by S5/S9/S10). |
| `--timeout DUR` | Per-scenario wall-clock cap. Default 5m. |
| `--quiet` | Suppress stdout; JSONL audit log is unchanged. |

## Examples

**Full pass:**

```
fleetctl usecase-tests
```

**Just the delegation + observation subset:**

```
fleetctl usecase-tests --scenario S1,S2,S5,S6,S7,S8
```

**Fast pass without LLM calls:**

```
fleetctl usecase-tests --skip-llm
```

**JSON for piping into jq:**

```
fleetctl usecase-tests --format json
```
