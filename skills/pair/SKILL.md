# pair

**Trigger:** `/pair`

## Summary

Manage DM pairing tokens (CRUD + budget limits for external callers).

## Arguments

| Flag | Meaning |
|---|---|
| `create [--label NAME]` | Create a new pairing; token is shown once. |
| `list` | List all pairings. |
| `show <id>` | Show pairing details + today's budget state. |
| `revoke <id>` | Revoke a pairing (idempotent). |
| `budget <id> --max-requests N --max-cost-cents N` | Update daily limits. |

## Examples

**Create labeled pairing:**

```
fleetctl pair create --label "acme-corp-prod"
```

**List pairings:**

```
fleetctl pair list
```

**Set $50/day cap:**

```
fleetctl pair budget abc123 --max-cost-cents 5000
```
